# INKARRI

Prototipo de videojuego 2D desarrollado con Godot y GDScript, con una identidad visual inspirada en la cultura andina.

## Sobre el proyecto

El jugador avanza por salas, combate enemigos y obtiene mejoras para sus estadísticas. El proyecto se encuentra en desarrollo; este repositorio muestra el estado actual de la implementación.

## Funciones implementadas

- Movimiento y combate a distancia.
- Enemigos con distintos comportamientos.
- Salas de combate y de objetos, conectadas mediante portales.
- Mejoras del personaje configuradas como recursos.
- HUD, menú de pausa y pantalla de derrota.
- Progresión hacia una sala de jefe.

## Controles

| Acción | Teclas |
|---|---|
| Moverse | W, A, S, D |
| Atacar | Flechas |
| Interactuar | E |
| Pausar | Esc |

## Requisitos

- Godot 4.7

## Cómo ejecutar

1. Clona o descarga este repositorio.
2. Abre `project.godot` con Godot.
3. Ejecuta el proyecto desde el editor.

## Tecnologías

- Godot Engine
- GDScript

## Estructura

- `escenas/`: escenas del juego, personaje, enemigos y salas.
- `recursos/`: estadísticas, mejoras y objetos configurables.
- `sprites/`: elementos visuales.
- `sonidos/` y `musica/`: recursos de audio.
